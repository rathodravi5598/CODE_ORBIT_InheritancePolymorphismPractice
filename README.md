# 🧬 Java Inheritance & Polymorphism Practice System

A hands-on demonstration of core **Object-Oriented Programming (OOP)** principles in Java, developed as part of the **Java Programming Virtual Internship** at **CodeOrbit Tech** (Batch IND1).

---

## 📌 Project Overview
This project showcases real-world implementations of **Inheritance** (code reusability via parent-child class relationships) and **Polymorphism** (method overriding and dynamic method dispatch) in Java. It models hierarchical domain models to write modular, scalable, and clean code.

---

## ✨ Key OOP Concepts Demonstrated

* **Inheritance (`extends`)**: Demonstrates hierarchical code sharing where child classes inherit state and behaviors from base/super classes.
* **Method Overriding (Runtime Polymorphism)**: Subclasses provide specific implementations for methods defined in superclasses using the `@Override` annotation.
* **Encapsulation**: State protection using `private` attributes with public getters and setters.
* **Dynamic Method Dispatch**: Instantiating subclass objects using superclass reference variables to achieve runtime polymorphism.
* **`super` Keyword**: Invoking superclass constructors and overridden parent methods cleanly.

## ⚙️ How to Setup & Run

1. **Clone the repository:**
   ```bash
   git clone https://github.com/rathodravi5598/CODE_ORBIT_InheritancePolymorphismPractice.git
   ```

2. **Navigate to the project folder:**
   ```bash
   cd CODE_ORBIT_InheritancePolymorphismPractice
   ```

3. **Compile the Java files:**
   ```bash
   javac *.java
   ```

4. **Run the application:**
   ```bash
   java Main
   ```
   *(Note: If your entry point file has a different name, replace `Main` with your main file name, e.g., `App`)*
